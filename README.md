# PIVOT installers

Public **Windows installers only**. Application source lives in a private repository.

## Download

Use **[Releases](https://github.com/diny-hou/Pivot-releases/releases/latest)** — not this git tree.

Typical files on each release:

- `PIVOT_<version>_x64-setup.exe` — NSIS installer
- `PIVOT_<version>_x64-setup.exe.sig` — updater signature
- `update.json` — Tauri v2 updater manifest (fetched by installed apps)

Installed copies check:

`https://github.com/diny-hou/Pivot-releases/releases/latest/download/update.json`
